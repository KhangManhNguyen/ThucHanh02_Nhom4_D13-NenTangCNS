# Bài thực hành 1: Trộn thư dữ liệu từ Excel

**Người thực hiện:** Nguyễn Quốc Huy - B2613106

## Các tập tin
| Tập tin | Nội dung |
|---|---|
| `Nhiem_vu 1.1.xlsx` | Cơ sở dữ liệu trộn thư, Sheet1 gồm 7 dòng với các cột Title, First_name, Surname, Address, City, Country |
| `Buoi1_Bai2.docx` | Tập tin chính (Main Document) chứa các trường trộn thư |
| `Buoi02_Nhom4_Bai_1.docx` | Kết quả sau khi trộn thư, gồm 7 bức thư |

## Các bước thực hiện
1. Tạo tập tin Excel làm cơ sở dữ liệu cho việc trộn thư.
2. Tạo tập tin chính trong Word, dùng Mailings > Select Recipients để chọn nguồn dữ liệu, chèn các trường Title, First_name, Surname, Address, City, Country bằng Insert Merge Field.
3. Dùng Finish & Merge > Edit Individual Documents > All để xuất kết quả ra tập tin riêng.
